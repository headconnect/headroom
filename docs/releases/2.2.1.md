# Rations 2.2.1

- Fixed usage checks running far more often than intended. Anthropic recomputes
  each limit's reset time on every request, drifting forward by a few
  milliseconds per second. Rations counted that drift as changed usage, so it
  stayed on its fastest 2-minute schedule instead of easing off to 20 minutes
  when nothing was happening - roughly ten times the intended number of
  requests, which could lead to rate limit errors. Reset times no longer count
  as a change; only usage does.
- A rate limit response now always holds the full 20-minute pause. It could
  previously be cut back to 30 seconds when a limit was about to reset.

No settings or accounts change. Usage still updates every 2 minutes while the
numbers are moving.
